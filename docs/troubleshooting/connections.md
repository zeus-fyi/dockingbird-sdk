# Troubleshooting index: configs, connections and host resources

Find a message id below to see when Dockingbird prints that message. Add `--verbose` to a command and every message also shows its id. With `--json`, each envelope carries the id as its `id` key. Each id links to its entry in the [catalogue](../troubleshooting.md): the message text, the next step and the exit status. This page holds the 209 ids about your own commands, connections, served resources, browsers and watch.

| [`LOCAL_MODEL_RUNNER_OFF`](../troubleshooting.md#local_model_runner_off) | You started an agent whose config names a local model, and Docker Model Runner isn't running on this Mac (Docker Desktop leaves it off until you turn it on), so nothing was started. |
| [`LOCAL_MODEL_RUNNER_UNREADABLE`](../troubleshooting.md#local_model_runner_unreadable) | You started an agent whose config names a local model, and `docker model status --json` or `docker model ls --json` answered something Dockingbird doesn't read, such as a Docker Model Runner far older or newer than this release knows, so nothing was started. |
| [`LOCAL_MODEL_RUNNER_KIND`](../troubleshooting.md#local_model_runner_kind) | You started an agent whose config names a local model, and Docker Model Runner here is Docker Engine's or Docker Cloud's, not Docker Desktop's. |
| [`LOCAL_MODEL_BACKEND_MISSING`](../troubleshooting.md#local_model_backend_missing) | You started an agent whose config names a local model, and Docker Model Runner has no vLLM backend installed, which the model runs on, so nothing was started. |
| [`LOCAL_MODEL_BACKEND_NOT_READY`](../troubleshooting.md#local_model_backend_not_ready) | You started an agent whose config names a local model while Docker Model Runner's vLLM backend was still installing, or was in error (the message shows Docker's words), so nothing was started. |
| [`LOCAL_MODEL_NOT_PULLED`](../troubleshooting.md#local_model_not_pulled) | You started an agent whose config names a local model that Docker Model Runner hasn't pulled on this Mac, so nothing was started. |
