# Troubleshooting index: the fleet, swarms and the work queue

Find a message id below to see when Dockingbird prints that message. Add `--verbose` to a command and every message also shows its id. With `--json`, each envelope carries the id as its `id` key. Each id links to its entry in the [catalogue](../troubleshooting.md): the message text, the next step and the exit status. This page holds the 227 ids about hosts, the fleet scheduler, the control plane, swarms and the work queue.
